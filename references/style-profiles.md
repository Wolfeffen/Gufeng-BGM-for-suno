# 风格原型与乐器库

## 四类原型

### A 空山幽谷型

- 代表作品：空山回响
- 适用画面：远景、空镜、自然与古建同框
- 默认速度：散板至行板
- 主奏：洞箫
- 配器：手碟淡入、手鼓点缀、大混响
- 情绪：空灵、悠远、静谧
- 律动：松散、氛围化
- 结构：单线推进，留白多
- Suno 风格句：古风，氛围音乐，民族乐器，山林，空灵，洞箫主奏，手碟淡入，手鼓点缀，大混响，稀疏留白

### B 庙宇梵音型

- 代表作品：庙音回声
- 适用画面：室内慢推、香火、光影细节
- 默认速度：行板
- 主奏：洞箫转竹笛
- 配器：悠扬空灵女声吟唱、大提琴、合成器 pad、极轻鼓点
- 情绪：空灵、安静、悠远、静谧
- 律动：鼓点弱
- 结构：两段式，从空间感进入叙事
- Suno 风格句：古风，氛围音乐，民族乐器，庙宇，静谧，洞箫转竹笛，混响回音，大提琴铺底，合成器 pad，鼓点极轻

### C 旅途行进型

- 代表作品：寻古之旅（公路）
- 适用画面：公路、脚步加快、接近古迹
- 默认速度：中板
- 主奏：竹笛或古琴
- 配器：琵琶扫弦、电鼓、大鼓、citypop 律动
- 情绪：行进、探索、开阔
- 律动：有推进感
- 结构：两段式，从慢到动
- Suno 风格句：古风，氛围音乐，民族乐器，citypop，行进，竹笛或古琴主奏，琵琶扫弦，电鼓律动，大鼓，两段式推进

### D 殿宇探秘型

- 代表作品：庙堂探境
- 适用画面：殿内穿行、转折、特写镜头
- 默认速度：中板偏缓
- 主奏：大鼓或鼓点驱动，古琴或琵琶
- 配器：神秘留白、短促段落
- 情绪：神秘、叙事、沉静
- 律动：有驱动感
- 结构：短促、探索感强
- Suno 风格句：古风，氛围音乐，民族乐器，探秘，叙事，大鼓或鼓点驱动，古琴或琵琶主奏，段落短促，神秘留白

| 功能 | 乐器 |

## 速度档位

| 档位 | 参考速度 | 用途 |
| --- | --- | --- |
| 散板 | 无固定节拍 | 留白、空镜、开篇 |
| 行板 | 66-76 BPM | 庙宇、园林、安静氛围 |
| 中板 | 76-96 BPM | 行走、探秘、渐进 |
| 中速律动 | 96-116 BPM | citypop、脚步加快、公路 |

## 人声规则

- 必须写“悠扬空灵的女声无词吟唱”这类气质描述，不要只写“女高音”，否则容易触发花腔炫技，抢走氛围主体。
- 同时写明“无词吟唱、无歌词”，避免 Suno 自动生成歌词。
- 需要更轻的质感时，可以追加“轻盈、气声、飘浮感”。
- 用户没有要求吟唱时，不要默认加入人声。
