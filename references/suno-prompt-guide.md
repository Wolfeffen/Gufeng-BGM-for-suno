# Suno 输入规则

## 四字段结构

```text
描述：<用途 + 纯背景音乐无歌词 + 段落结构 + 每段乐器与过渡>
风格：古风，氛围音乐，民族乐器，<原型标签>，<地域标签>
情绪：<2 到 4 个词>
节奏：<速度档位>
```

## 字段规则

- 描述字段写画面用途、纯音乐无歌词、段落结构和每段乐器/过渡。
- 风格字段用具体乐器与音色，控制在 50 到 120 词；不要堆抽象形容词。
- 情绪字段 2 到 4 个词，节奏字段写速度档位。
- 主奏乐器一次只给一个强方向，避免“洞箫和琵琶同时主奏”这类冲突。
- 出现女声吟唱时写“悠扬空灵的女声无词吟唱”，禁止只写“女高音”，避免触发花腔炫技；同时写明无歌词。
- 需求未提及地域/朝代时，不添加地域标签；提及时只加 1 到 3 个地域特征。

## 反面案例

| 弱写法 | 强写法 |
| --- | --- |
| 空灵、好听 | 洞箫主奏，大混响，稀疏留白 |
| 女高音 | 悠扬空灵的女声无词吟唱，轻盈气声，飘浮感 |
| 中国风一点 | 古风，民族乐器，宫调式明亮旋律 |
| 加一点地域感 | 融入西域丝路色彩，曲颈琵琶，筚篥，石窟混响 |

## 修改建议

- 更安静/太吵：删鼓点或标注极轻，减少乐器标签，加稀疏、留白、pad 铺底。
- 太满/太密：简化段落，减少同时演奏乐器，加长混响尾巴。
- 更有律动：加电鼓、citypop bass、琵琶扫弦，速度升一档。
- 地域味太重：只保留 1 到 2 个地域特征标签，主奏与结构回到默认原型。
- 一次只改一个方向，避免同时调整速度、配器和结构。
