# 现有作品档案

归档用于保持风格一致性。原始提示词未提供的作品，按成品听感和用户任务需求记录。

## 空山回响

- 时长：2:18
- 原型：A 空山幽谷型
- 任务需求：由洞箫主奏中等速度的空灵氛围音乐，用于古建照片配乐；纯背景音乐，无歌词；前半部分以洞箫和庙宇混响回音为开篇，逐渐加入手碟和手鼓，营造徐徐靠近的空间感受；之后接入更有律动的电鼓，旋律声部改为竹笛和古琴；后半部分加入大鼓和鼓点，融合 citypop，加入琵琶扫弦。
- 原始 Suno 描述：洞箫主奏中等速度空灵氛围音乐，古建照片配乐，纯背景音乐无歌词；两段式，前半以洞箫与庙宇回音开篇，手碟手鼓加入，再接电鼓加快脚步，主奏改竹笛古琴；后半加入大鼓，融合 citypop，旋律加入琵琶扫弦。
- 风格：古风，氛围音乐，民族乐器，citypop；情绪：空灵、悠远、静谧；节奏：中等。
- 备注：成品实际听感更偏松散留白，故归档为 A 型而非 C 型。

## 庙音回声

- 时长：3:14
- 原型：B 庙宇梵音型
- 任务需求：需要更安静的氛围，整体速度减慢为行板，鼓点弱化；前半保留洞箫和混响，手碟淡入，随后洞箫改竹笛，混响回音加大，加入女声吟唱，低声部加入大提琴，中声部加入合成器 pad 加厚整体音效。
- 原始 Suno 描述：安静氛围，行板慢速，鼓点弱化，纯背景音乐，不需要歌词。结构：前半部分保留洞箫和庙宇混响回音，手碟淡入，随后洞箫改为竹笛，加大混响回音，加入女声吟唱，低声部加入大提琴，中声部加入合成器 pad 加厚整体音效。
- 风格：古风、氛围音乐、民族乐器；情绪：空灵、安静、悠远、静谧；节奏：行板，慢速。
- 备注：人声统一写“悠扬空灵的女声无词吟唱”，不写“女高音”。

## 寻古之旅（公路）

- 时长：2:49
- 原型：C 旅途行进型
- 任务需求：与《空山回响》《庙音回声》同属古建漫游 BGM，类型相似，强调旅途与渐进。
- 备注：原始提示词未提供；按成品听感记录为竹笛/古琴主奏、琵琶扫弦、电鼓与大鼓推进、citypop 律动。
